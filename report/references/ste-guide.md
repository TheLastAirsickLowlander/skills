# STE-inspired writing guide

The report reader may be tired, busy, or not a native English speaker. These rules
exist so that every sentence has exactly one possible reading. This is the spirit of
ASD-STE100, not the full controlled vocabulary — apply the spirit.

## Sentence rules

- **Short sentences.** Aim for 20 words or fewer. The checker warns over 25.
- **One idea per sentence.** If a sentence joins two facts with "and", "but", or
  "so", split it.
- **One instruction per sentence** in procedures. Imperative mood: "Run the script.
  Record the number."
- **Active voice.** "The change removed 120 ms" — not "A reduction of 120 ms was
  observed."
- **Present tense for facts.** "The pipeline takes 7 min."
- **No hedging about facts.** The data showed it or it did not. Write "The p95 fell
  by 310 ms." Put interpretation in the analysis section and mark it: "This suggests
  the cache was cold."
- **Numbers carry units.** "310 ms", "4.2 %", "7 min", "$38/day". Never a bare
  number.
- **Keep the same word for the same thing.** Do not alternate "pipeline", "workflow",
  and "build". Pick one term, put it in the glossary, use it everywhere.

## Word swaps (prefer the left word)

|---|---|
| use | utilize, employ |
| show | demonstrate, display (v.), indicate |
| start, begin | commence, initiate |
| stop | terminate, halt |
| end | finalize, conclude |

| before | prior to, in advance of |
| after | subsequent to |
| about | approximately, circa |
| enough | sufficient, adequate |

| get | obtain, acquire |
| keep | retain, preserve |
| need (v.) | require, necessitate |
| help | facilitate, assist |
| make sure | ensure, guarantee |
| find out | ascertain, determine |
| tell | inform, notify |

## Paragraph rules

- One topic per paragraph. First sentence says the topic.
- Six sentences per paragraph is a soft maximum.
- Lists are better than prose for 3+ parallel items.

## What to do with jargon

Technical terms are allowed. Define each one in the glossary in one line, the first
time it matters. If a plain word exists, the plain word wins.
